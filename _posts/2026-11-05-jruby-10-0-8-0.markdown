The JRuby community is pleased to announce the release of JRuby 10.0.8.0.

* Homepage: [https://www.jruby.org/](https://www.jruby.org/)
* Download: [https://www.jruby.org/download](https://www.jruby.org/download)

JRuby 10.0.x targets Ruby 3.4 compatibility.

Thank you to our contributors this release, you help keep JRuby moving forward!

JRuby activity has increased over the last several months, and this release contains dozens of bug fixes and performance improvements from new contributors. This page will be updated with targeted release notes later today.
